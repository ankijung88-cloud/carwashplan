# 🚗 세차 플랜 (CARWASH PLAN) - 고객 가입 & 운영 매뉴얼

찾아가는 프리미엄 출장세차 모바일 고객 가입 랜딩 페이지 및 관리 시스템입니다.

---

## 📋 주요 기능
1. **모바일 최적화 고객 랜딩 페이지**:
   - 요금 안내 매트릭스, 차종 선택, 추가 케어 옵션 선택, 이용 희망 요일 및 방문 장소 지정
   - 인터랙티브 시공 갤러리 (루프 슬라이더 & 고화질 확대 뷰어)
2. **구글 스프레드시트 실시간 자동 저장**:
   - 고객 신청 시 1초 만에 구글 시트에 행 단위로 실시간 누적 저장 (`google-apps-script.js`)
3. **텔레그램 스마트폰 실시간 알림**:
   - 신규 가입 신청 즉시 사장님 스마트폰으로 고객명, 연락처, 차종, 플랜 전문 푸시 알림
4. **관리자 가입 확인 센터 (웹 내장)**:
   - 가입 내역 검토/승인/반려, CSV 엑셀 다운로드, 시공 사진 직접 업로드 및 수정, 연동 설정 탭

---

## 1. 📊 구글 스프레드시트 연동 방법 (1분 완성)

1. [Google 드라이브](https://drive.google.com)에서 **[새로 만들기] > [Google 스프레드시트]**를 생성합니다.
2. 상단 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
3. 기존 편집기 내용을 모두 지우고, 프로젝트 내 **[`google-apps-script.js`](./google-apps-script.js)** 파일의 전체 코드를 복사하여 붙여넣고 저장(`Ctrl + S`)합니다.
4. 우측 상단 **[배포] > [새 배포]**를 클릭합니다:
   - **유형 선택 (톱니바퀴 아이콘)**: `웹 앱` 선택
   - **설명**: `세차 플랜 신청 연동`
   - **다음 사용자로 실행**: `나 (내 Google 계정)`
   - **액세스 권한이 있는 사용자**: **`모든 사용자 (Anyone)`** ★ 필수!
5. **[배포]** 버튼을 누르고 **[액세스 승인]**을 완료합니다.
6. 생성된 **웹 앱 URL** (예: `https://script.google.com/macros/s/.../exec`)을 복사합니다.
7. 웹사이트 우측 상단 **[관리자 확인]** 버튼 클릭 → **[구글시트 & 알림 연동]** 탭에 URL을 붙여넣고 **[연동 설정 저장하기]**를 누르면 끝납니다!

---

## 2. 🔔 텔레그램 스마트폰 실시간 푸시 알림 연동 방법

1. 스마트폰이나 PC에서 **텔레그램** 앱을 실행합니다.
2. 상단 검색창에 **`@BotFather`**를 검색하여 대화를 시작하고 `/newbot`을 입력합니다.
3. 봇 이름과 사용자명을 입력하면 **`HTTP API Token`** (예: `7123456789:AAHKz...`)을 발급해줍니다.
4. 검색창에 **`@userinfobot`**을 검색하여 대화를 시작하면 내 **`Id (Chat ID)`** (예: `123456789`)를 알려줍니다.
5. 내가 만든 봇을 검색하여 **[시작(Start)]** 버튼을 한 번 눌러줍니다.
6. 웹사이트 **[관리자 확인]** → **[구글시트 & 알림 연동]** 탭에 **봇 토큰**과 **채팅 ID**를 입력하고 **[연동 설정 저장하기]**를 누르면 완료됩니다!

---

## 3. 🌐 Vercel 무료 배포 방법

1. [Vercel](https://vercel.com)에 로그인 (GitHub 계정으로 간편 로그인 추천)
2. **[Add New...] > [Project]** 클릭 후 본 저장소를 선택하여 **[Deploy]**를 누르면 약 30초 만에 `https://carwash-plan.vercel.app` 형태의 고유 URL이 발급됩니다.
3. 이 URL을 고객 홍보용 링크, 카카오톡 채널, 명함/전단지 QR코드로 바로 활용하시면 됩니다!
